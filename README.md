# PoE Umbra Atlas Planner

An Atlas passive tree viewer with a path planner for Path of Exile.

**Live site:** https://mrthundergod.github.io/poe-umbra-atlas-planner/

## Features
- Click nodes to allocate; the shortest path from the centre fills in automatically.
- **Plan path** wizard: main mechanic, up to two secondary mechanics, Eldritch influence, keystones,
  travel-node priorities (pack size, threads, …) and a point budget. Finds the best route from the centre,
  covering whole clusters and avoiding keystones you don't want.
- Optional 150-point goal that grows out of a smaller tree, so you can work toward it.
- Save / load trees as files, share via the page link, and export a high-resolution PNG with your plan summary.
